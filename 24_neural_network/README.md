# Neural Network - MNIST Digit Recognition 🧠

## Description
Deep learning neural network built with PyTorch
achieving 97%+ accuracy on handwritten digit recognition.

## Tech Stack
- Python (PyTorch, Matplotlib)
- Jupyter Notebook
- MNIST Dataset (70,000 images)

## Results
- Training samples: 60,000
- Test samples: 10,000
- Target accuracy: 97%+

## How to run
pip install torch torchvision
Open neural_network.ipynb
