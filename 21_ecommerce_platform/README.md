# E-commerce Analytics Platform 🛒

## Live Demo
https://ecommerce-platform-3zli.onrender.com

## Description
Full-stack e-commerce analytics platform with web scraping,
SQL database, ML model and Flask web app.

## Pages
- / — Homepage with stats
- /products — All books with prices
- /insights — Top expensive and rated books

## Tech Stack
- Python (Flask, BeautifulSoup, Pandas, Scikit-learn)
- SQLite
- Deployed on Render

## How to run
pip install -r requirements.txt
python app.py
